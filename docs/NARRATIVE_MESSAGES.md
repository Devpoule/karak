# Convention des messages narratifs

Les notifications décrivant une action ou un événement utilisent la troisième
personne. Lorsqu'un héros est identifiable, son nom officiel doit apparaître
dans le message : `Aderyn récupère tous ses points de vie.`

Les messages narratifs ne doivent pas employer « vous », « votre » ou « vos ».
Cette règle concerne les combats, découvertes, objets, pouvoirs, malédictions,
soins et événements de partie. Les libellés génériques de l'interface comme
« Nouvelle partie », « Continuer » ou « Lancer le dé » restent inchangés.

Les noms sont obtenus depuis les définitions officielles des héros. Un message
qui implique plusieurs héros doit nommer explicitement chaque protagoniste.
